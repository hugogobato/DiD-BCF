# Validation scope

`package_checks.json` records verification of the exact 4,836-job partition, all 264 compact reused fits, eight previously saved B3 anchor exports, agreement with the frozen paper-metric definitions, corrected bias Monte Carlo standard errors based on estimation errors, atomic metrics recovery, corruption/path rejection, and all 65 notebooks with 322 valid Python code cells.

The draw-based worker fixture consumes three already-sampled local baseline chains in a temporary recovery namespace. It prohibits new sampling subprocesses, reproduces pooled scalar and treated CATT summaries exactly, and checks that successful raw scratch is removed while the metrics ZIP resumes correctly. Its remapped metadata and outputs are validation fixtures and are not part of the scientific results.

`checkout_checks.json` records an isolated sparse checkout of the immutable helper commit used by every notebook. Five collected tables agree byte for byte with the workspace collection. The actual matching local native binary was revalidated with native and fixed eligible-feature controls. This check reused that binary; the unchanged builder had already passed a fresh one-worker build in the earlier transfer validation. Fresh Colab downloads, compilation and runtime timings are user-run steps.

No new production fits were launched during this preparation. The validation records are infrastructure checks, not evidence of estimator accuracy or successful MCMC convergence.
