# Archived revision DiD-BCF experiments

This folder preserves earlier correction workflows and proper-prior campaign materials. The current repaired paper rerun is maintained at `Simulation_Studies_Revision/DiD_BCF/Paper_Rerun_20261011/`.

`DiD_BCF/Correction_Completion_Notebooks/` contains the 219 completion notebooks, and `DiD_BCF/Theory_Calibration/` contains the 101 correction-audit, information-ablation, and pilot notebooks. `Proper_Prior_Rerun/` contains the earlier campaign definitions and documentation. Its `Paper_Rerun_20261011/` child is a compatibility symlink to the current repaired campaign.

The former repository path `Simulation_Studies_Revision/Proper_Prior_Rerun/` is also a compatibility symlink to `Proper_Prior_Rerun/`, preserving historical audit and notebook references. The original notebook contents and run results remain publishable. The separate `.local_experiment_archive/` remains excluded from Git.

The migration record at [MIGRATION_RECORD_20261014.json](MIGRATION_RECORD_20261014.json) lists moved file counts, regular-file byte totals, path inventories, and SHA-256 hashes before and after each move.
